# Dashboard

The dashboard gives a quick view of your Datamingle workspace.

## Dashboard Cards And Charts

Depending on available data, the dashboard can show:

- platform users,
- data sources,
- SQL workflows,
- query workflows,
- instance type distribution,
- instance environment matrix,
- SQL query activity,
- SQL syntax type distribution,
- SQL release trend,
- workflow status distribution,
- rows retrieved by user,
- top databases by retrieved rows.

Use the dashboard to confirm your user context before operational work.
