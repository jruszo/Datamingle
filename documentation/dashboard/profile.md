# Profile

The profile page shows your identity and WorkOS session details.

## Profile Information

The profile page can include:

- username,
- display name,
- email,
- permission groups,
- resource groups,
- WorkOS profile details,
- active WorkOS sessions,
- security and identity information.

If groups or resource groups are wrong, contact an administrator. In Directory Sync environments, some memberships must be changed in the directory source.
