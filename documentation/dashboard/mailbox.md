# Mailbox

Mailbox is your personal work queue.

## Categories

| Category | Meaning |
| --- | --- |
| Approval needed | A workflow, archive, or access request is waiting for your review. |
| Execution needed | Approved work is waiting for an eligible executor. |
| Execution finished | Work has completed and may need your attention. |

## Filters

You can filter by:

- all, unread, or read items,
- category,
- source type.

Source types include SQL workflows, archives, and permission requests.

Opening a mailbox item takes you to the relevant detail page.
