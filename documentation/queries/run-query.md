# Run A Query

## Steps

1. Open `Queries`.
2. Select an instance.
3. Select a database and schema if applicable.
4. Inspect metadata if needed.
5. Enter SQL in the editor.
6. Set an appropriate row limit.
7. Run the query.
8. Review the result grid and execution information.

## Result Information

Query results can show:

- rows,
- columns,
- affected row count,
- execution time,
- replica lag information where available,
- masking status.

## If The Instance Is Missing

Check both your access and the agent assignment. Query selectors only show services with an online command-capable agent and active websocket.
