## First Workflow

1. Sign in with email/password.
2. Open `Dashboard` to confirm your groups and teams.
3. Use `Queries` for online read queries.
4. Use `Workflows` for DDL, DML, or export requests.
5. Use `Permission Management` if you need more access.
6. Watch `Mailbox` for approvals, execution tasks, and completion notices.
