# Navigation And Access

Datamingle only shows menus and actions that your user can access.

## Common Menus

| Menu | Purpose |
| --- | --- |
| Dashboard | Profile and activity overview. |
| Inventory | Registered database services. |
| Agents | Agent installation, assignments, and commands. |
| Workflows | DDL, DML, and export workflows. |
| Archives | Data-retention deletion workflows. |
| Queries | Online SQL query workspace. |
| Permission Management | Access requests and active grants. |
| Audit | Audit logs for platform activity. |
| Reports | Operational reporting. |
| Settings | Administrative controls. |

## Why A Menu Is Missing

A menu is usually missing because your account lacks the required permission.
Ask an administrator to check your permission groups and teams.

If you only need access to one service for a limited time, use `Permission Management` when available.
