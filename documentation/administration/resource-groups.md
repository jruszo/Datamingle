# Resource Groups

Resource groups connect users and database services. In the current SPA, these
are shown as `Teams`; legacy pages and APIs may still use `resource group`.

## Common Actions

- create teams,
- edit group names,
- assign users,
- assign servers,
- delete groups where allowed.

Resource groups are central to Datamingle access. Add instances to the correct
teams before expecting users to see them in query, workflow, archive, or
permission request flows.
