# Workflow Statuses

| Status | Meaning |
| --- | --- |
| Pending review | Waiting for reviewers. |
| Approved | Review flow passed. |
| Scheduled | Approved and scheduled for a future run. |
| Queued | Waiting for dispatch. |
| Executing | Agent is running the command. |
| Finished | Execution completed successfully. |
| Execution failed | Execution failed or result persistence failed. |
| Canceled | Request was canceled or rejected. |
| Auto-rejected | SQL review failed an automatic rule. |

Use the workflow detail page for the exact approval flow, SQL review result, execution result, and workflow log.
