# Review And Approval

Open a workflow detail page to review the request.

## Detail Sections

Workflow detail can show:

- approval flow,
- workflow policy name when one was captured at submission,
- current reviewers,
- SQL content,
- SQL review result,
- execution result,
- workflow log.

## Review Actions

Reviewers can approve, reject, or cancel when they are eligible for the current approval step.

Add a useful remark, especially when rejecting or canceling a workflow.
