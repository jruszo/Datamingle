# Data Dictionary

The data dictionary lets authorized users inspect database metadata.

## Typical Use

Use the data dictionary to inspect:

- databases,
- schemas,
- tables,
- columns,
- object metadata.

This helps users write queries or workflow SQL without directly connecting to the database.

## Missing Objects

If an object is missing, check:

- your access,
- database visibility filters on the instance,
- metadata refresh timing,
- whether the service is reachable.
